# CoffeeStrap 0.9.5

Independent local fork of [Froststrap](https://github.com/Froststrap/Froststrap), derived from Fishstrap and Bloxstrap. Avalonia desktop launcher with the existing espresso/cream design. This development workflow does not install the app or change protocol handlers.

## What changed

- **Cloud volume maps:** independently choose Original / 50% / 25% dimensions for default 3D cloud shape/detail maps and their 2D fallback. The launcher keeps existing R8/BC4 mip data and applies the choice after installed mod priority on the next launch. Original removes the budget; disabling the mod/budget restores preserved files exactly. Only experiences using these default clouds are affected; cloud simulation stays enabled. Ten installed-source outputs pass real Direct3D WARP creation, shader-resource-view creation and exact mip readback. This proves resource compatibility in that isolated software device, not Roblox visuals or FPS/VRAM gains on a user's GPU.
- The texture reducer now skips a requested block-compressed base mip whose width/height is not aligned to four pixels. Such tiny/unaligned outputs can fail Direct3D creation. The source stays in place and the real mod report explains the skipped budget. Existing full mip chains retain their normal smaller sublevels.
- **Alt+Enter fullscreen:** choose Roblox default, Native fullscreen or Roblox-handled using the existing allowlisted fullscreen flag. Save and relaunch before pressing Alt+Enter in game. Renderer and driver support varies, and native mode can affect popouts, cursor behavior or switching apps; no FPS improvement is promised. The renderer is left as selected. Explicit global handling wins over an assigned experience profile; choosing Roblox default removes that global override and permits the profile's choice. Restore Roblox visuals also clears it.
- **Smaller single EXE:** 48,003,750 bytes (45.78 MiB), down 25.49% from 0.9.1. Windows selects its own Avalonia backend directly, excludes development hot reload and duplicate UI assets, and ships only the linked Ed25519 verification code from the existing Bouncy Castle library. It still requires the installed .NET 10 x64 runtime. The 10 MB target has not been achieved.
- **Lighter browser sign-in:** a small client for Chromium's documented DevTools protocol replaces Puppeteer and WebDriver. It starts an installed compatible browser with a separate temporary profile, retains the browser sandbox, reads the Roblox sign-in cookie through the browser API and closes its owned session gracefully. It does not inspect personal browser profiles or download a browser. Quick sign-in and manual sign-in remain available. Actual account authentication still needs a user login; native tests use synthetic cookies only.

- **Live windowed render size:** apply 1920×1080, 1600×900, 1280×720 or 960×540 client dimensions to a running player without restarting. Refresh players and choose explicitly when several are running. Restore previous size keeps the first size/position across preset changes; Keep this size, leaving Game Tweaks or closing Settings keeps the applied geometry and clears that page's restore point. Later manual resizing or fullscreen changes are respected. The full-width player picker, wrapping actions and inline status fit narrow/wide layouts in both themes and support keyboard access and reduced motion. No live FPS-cap control is claimed.
- **Windowed render size** also saves the selected preset for the next launched player. It fits the monitor work area, preserves graphics 10 / effects 1, skips fullscreen/maximized/minimized windows and applies once. An unchanged watcher-owned window restores when its session ends. No driver or desktop resolution is modified. Actual Roblox framebuffer behavior and performance still need gameplay validation.
- **Plain stud surfaces** replace the default shading atlas with compact opaque neutral detail. **Cloud detail maps** now have an independent Original / 50% / 25% mip budget. Both use existing mod priority, preserved originals, application reports and exact-file restoration. Custom game assets can supersede default textures; gameplay and FPS gains need in-game validation.
- **One Release folder** contains a single Windows x64 executable and license notices. The executable excludes .NET; install the .NET 10 x64 runtime before running it. Runtime/debug symbols, duplicate ZIPs and old build histories are not distributed.

- **Save recovery** keeps the launcher open when a settings write fails, blocks Save-and-launch/restart and waits to apply pending file changes. A persistent panel identifies failed files, explains partial saves and offers keyboard-accessible Retry save, including on Home. Old success notices clear on failure. JSON and Roblox XML use unique adjacent stages; failed replacements retain the previous file and pending edits. Failed mod-file tasks remain queued, while completed tasks are not replayed. Explicit Discard still closes without applying remaining work.
- **Performance-profile recovery** now checks the distance-preference write before changing rendering settings. Locked, read-only or invalid settings files show an error and preserve the previous Undo backup. A locked backup rolls back the saved distance preference; failed Restore keeps Undo available for retry. Other pending settings are preserved. Flags and Roblox XML still require Save and relaunch. These explicit file operations are not a cross-file crash transaction.

- **Assignment recovery** now pages saved place IDs in groups of 128, preserving hidden IDs when removing a row. Clear profile IDs and legacy Reset all assignments ask for confirmation and support one saved Undo until the dialog closes. Null/oversized legacy maps remain recoverable. External settings-file changes stop assignment writes, and failed writes retain the prior map and retryable Undo. The experience dialog has a compact footer and a visible confirmation panel with Escape-to-cancel, finite motion and reduced-motion support.
- Snapshot creation stops at the picker’s 256-file capacity with an actionable error instead of saving an unreachable file. Replace/rename remain available, selected assigned legacy files can be revealed in the bounded manager, and a persistent slot count explains capacity. Existing files are preserved.
- The **Snapshots** tab in Game Tweaks’ Manage experience profiles and advanced **Profiles** now use the same bounded, validated snapshot files as Game Tweaks. Rename/delete preserve assignments when a write or file lock fails; Replace snapshot writes through an adjacent temporary file. Copy awaits the clipboard and emits correctly escaped JSON. Load/presets stage supported values for review with Undo/Redo, keep selected global quality/renderer preferences, and require the main window’s Save settings action. The dialog stays open with success/error feedback, disables busy actions, cancels pending reads on close, and refreshes the advanced grid once without the old delayed duplicate action. The name editor and footer fit narrow windows in both themes. File and assignment operations save immediately.
- **Manage experience profiles** is now available in Game Tweaks. It reuses the existing named flag snapshots and place-ID assignments: save current supported flags, assign a place ID, or remove its assignment to return to global flags on the next launch. The focused espresso/cream dialog has Save, Experiences and Snapshots tabs, searchable entry access, keyboard save/assign/rename/close, clear empty/error states and finite feedback motion with reduced-motion support. Missing snapshots retain removable assignments. Assignments save immediately. Snapshots replace other per-place flags; selected global effects, texture, voxel-lighting and renderer preferences retain their existing priority. Native Roblox preferences, file mods and scheduling settings are separate.
- Profile launch preparation validates names, bounds reads, filters unsupported values before writing and replaces output through a staged file. Missing/invalid/conflicting profiles fall back to global flags with a file-mod report entry. Switching experiences or removing assignments restores globals, including defaults if the saved global flag file is absent. Saving one property now preserves unrelated pending edits, reports write failures and avoids truncating the previous settings document.
- **Hardware & window title** now offers the installed NVIDIA app, classic NVIDIA Control Panel and AMD Software independently, including mixed-GPU systems. Refresh hardware/path updates availability. Missing Store/custom-path apps have a Windows/Start fallback, and shell failures show a retryable inline message. The selectable read-only Roblox executable path and Show Roblox executable action follow the launcher's current static/versioned installation, making manual per-program driver preferences easier to target after updates. Opening a shortcut does not apply or verify a driver preference; reset/remove manual program preferences in the same Windows/vendor app to undo them.
- Settings search now matches words across titles, descriptions, pages and sections, ranks title matches first and shows section context. The slim 32-high field has Ctrl+K access, visible pending/no-results feedback and clear controls. Arrow/Enter or pointer selection reveals the specific real control, including duplicate titles and collapsed sections. Immediate Enter searches the current text. Search is local, bounded to 100 displayed matches, and a failed page index offers Retry. Closing the window cancels indexing and pending query work.
- **Texture resolution budget** adds independent Original / 50% / 25% dimension choices for default sky faces, water normal maps, plastic/stud surface maps and built-in effect sprites. It selects existing mip levels after mod priority resolution and keeps compression, channels and the remaining mip chain. Returning to Original removes the budget; disabled mods restore their preserved originals. Unsupported layouts are skipped and unreadable files report failure. It applies on the next launch, leaves distance/effect counts alone and does not alter game-provided custom asset IDs. Smaller source payloads were measured; live visual, VRAM and FPS effects remain unverified.
- **Last file-mod application** in Texture Editor shows applied, already-current, restored, removed, skipped, shadowed and failed events from the real launcher. Refresh and attention/status filters expose priority conflicts, missing mod folders and client textures. Reports are local, bounded and separate for Player/Studio; file-copy evidence does not prove an experience displayed a default asset.
- A corrupt non-DDS texture no longer aborts preparation of healthy assets. Its failure remains visible in the report and the existing launch warning. Locked original-file restores stay pending for a later launch, while other originals continue restoring. Cancellation waits for started copy tasks before disposing their report and never marks an interrupted preparation complete.
- **Compare settings** previews all 14 values a rendering profile owns, showing current unsaved values beside the selected profile. The comparison updates after manual effects/texture/mesh/MSAA edits, apply, undo and visual reset. It is keyboard accessible, animated and supports reduced motion.
- QoS and timer requests now fail and restore independently, preserving later changes to either mechanism. A native isolated-process probe verifies exact CPU/GPU/power restoration. Undo also checks that its backup can be retired before changing rendering settings, so a locked file cannot leave a partially restored UI.
- Four **Performance profiles** combine texture detail, effects, CSG distance, MSAA and grass settings while keeping the saved graphics slider at 10. Texture saver requests the lowest texture detail; it does not forcibly evict GPU allocations. Apply is explicit, with a validated persistent backup and a Restore previous profile action. Save and relaunch Roblox for these settings.
- Four opt-in **Windows session scheduling** settings request above-normal CPU priority, WDDM GPU priority, performance QoS and honoring the player's own timer-resolution requests. They use vendor-independent Windows APIs, report rejected requests, preserve higher existing priorities and restore owned changes when the watcher stops. They apply to the next CoffeeStrap-launched player; driver/access restrictions can limit availability. No global driver profile is changed and no FPS gain is promised.
- Shared option cards have tighter spacing, clearer typography and smaller corners across the active menus. Hover lifts are finite, interruptible, stop when detached and respect reduced motion. Group descriptions now wrap at narrow widths. Existing smooth scrolling, page transitions, expandable groups, artwork and compact-launcher animations remain.
- **Explosion layers** can retain only the default core/ring or hide four modern built-in explosion sprites. Original files restore through the normal mod pipeline. Custom game effects remain under the game's control, and transparent sprites do not remove particle simulation work.
- Hourly continuation is configured for UI review, real visual/performance feature work and supported live FPS research. Roblox's own in-game Maximum Frame Rate setting is the verified live route; no supported external hot-update API was established, and editing saved XML is not labeled as a live update.
- Mesh Detail is restored at levels 0–9, with the legacy saved-value rounding bug fixed. Advanced controls expose all four CSG LOD distances independently (0–10,000). Grass minimum/maximum distance and motion factor are separately configurable. Anti-aliasing, texture quality, renderer, DPI resolution, gray sky and voxel-lighting options remain opt-in. Restore Roblox visuals clears overrides and turns off the saved vignette/max-quality effects.
- **Maximum distance + lowest effects** pairs Roblox's saved graphics slider at **10** with `DFIntDebugFRMQualityLevelOverride=1`. The user confirmed this combination retains distant objects with low effects in their game. The maximum-distance preference re-applies the saved slider at save/load and immediately before a player launch; **Override Graphics Quality level** remains independently adjustable from 1–21. The old automatic FRM 21 rule is removed. Keep Roblox's in-game slider at maximum; lowering it during play can reduce distance. Experience streaming and fog still limit visibility.
- **Black-texture compatibility** offers Direct3D 11, texture detail 3 and normal voxel updates while preserving the selected graphics level. The reported dark textures were traced by the user to an installed mod; the renderer action remains optional troubleshooting. Selected global renderer preferences take priority over conflicting per-place flags. Plastic replacements preserve 128×2048 atlas / 512×512 detail dimensions, water maps preserve 256×256, and all supply complete mip chains.
- **Plastic textures + maximum distance** uses the same saved-slider-10 / FRM-1 pairing, texture override 3, saved MaxQuality/Vignette off, and flat built-in plastic color/normal/detail replacements. It does not claim to remove game-authored lighting or post effects.
- Built-in visual asset tweaks add Warm dusk/Deep blue/Overcast default skies, flattened water normal maps, flattened plastic color/normal/detail and hidden default sun/moon discs. They use the normal backup/restore pipeline. Installed content mods take priority; games that use custom textures can override default assets.
- Built-in effect styles recolor default fire/embers, smoke, sparkles and forcefields, with separate Hidden choices. Default restores original files; installed mods retain priority. These replace the shipping particle color/shape textures and do not override game-provided custom images or change gameplay state.
- Community texture mods resolve nested archive roots. PNG/JPEG data stored under DDS/TEX names is normalized into DDS with a complete mip chain. Image deletion markers now provide transparent textures instead of causing missing-asset errors. Skybox mods replace Roblox's six default sky images and, by default, map them to the existing six indoor faces too. Explicit indoor mod files take priority. Disabling restores original files. Custom sky IDs defined by a game are outside this file replacement path.
- Texture Editor has inline Disable/Enable and trash controls for installed mods, including installed content missing from the online catalog. Manage installed is removed. Uninstall moves source files into CoffeeStrap's ModTrash. The production launcher backs up original assets before new replacements and restores their bytes after disabling/uninstalling. Higher-priority enabled replacements win. Shader/executable injection payloads are rejected and excluded from mod application.
- The compact Play/Settings menu now includes a full-width, 32-high search field and a pinned-game strip at the bottom. It retains its 390-wide footprint and is 520 high to fit the added controls. Search filters saved pins; extra pins scroll horizontally, stars unpin, and artwork launches through CoffeeStrap. Both menus share the same pin view model and saved state. Home search, community search and sidebar search remain thin and vertically centered; Home pins remain below Continue and Recommended.
- RoValra regions can be enabled from Home. Real datacenter choices replace Auto-only selection. Normal public launches combine Roblox's population/capacity with RoValra's location metadata and select the most populated known non-full match. Explicit instance, private, reserved and friend joins retain precedence. Auto uses Roblox matchmaking. Provider failure does not silently substitute another region; the launcher's explicit Skip action permits normal matchmaking.
- Auto Reconnect uses confirmed network/inactivity disconnect events in the CoffeeStrap-launched player's log. It excludes intentional leaves, kicks, private/reserved sessions and unclassified teleports, with three attempts per five-minute window. Session options apply to subsequent launches. Reconnect uses the same CoffeeStrap launcher and selected region.
- Game Tweaks detects CPU/display adapters and opens available GPU driver settings or Windows graphics preferences. Driver profiles are not automatically altered. Game names follow launch/log/teleport state and Roblox universe metadata. FPS telemetry, its elevated helper and the bundled PresentMon tool are removed. No injection or game memory access is used.


RoValra server metadata: [Powered by RoValra](https://www.rovalra.com), [API schema](https://apis.rovalra.com/openapi.json), [terms](https://www.rovalra.com/tou/). Region selections persist immediately, including across provider toggles and failed refreshes. Both public pages and provider queries are cached for at least 60 seconds; individual server locations are reused for six hours. Cross-process request pacing and persisted Retry-After cooldowns reduce repeat 429s; short Retry-After responses receive one bounded retry. External throttling can still require waiting. Responses are credential-free; no Roblox credentials are forwarded to RoValra. Public-server searches stop after 20 pages/2,000 entries or 55 seconds. Counts and available slots can change before joining; provider coverage can be incomplete.

## Validation and outputs

Release builds, isolated production-mod application tests, mocked HTTP matching/cancellation/cache tests, UI interactions and rendered captures are recorded in VERIFICATION.md. Credential-free public Roblox/RoValra reads were exercised separately. The user confirmed the saved-slider-10 / FRM-1 combination in their running game; the agent verified launcher output separately. Other live visual behavior, automatic reconnect and native game-name captions still require validation. No performance improvement is claimed.

- Launch/share: `Release/CoffeeStrap.exe` with its small license notices.
- Current verification: `.build/verification/` (developer evidence, not required to run).

The executable requires the separately installed .NET 10 x64 runtime and extracts bundled application-native libraries to the normal user bundle cache. Download the runtime from https://dotnet.microsoft.com/download/dotnet/10.0 . Roblox downloads/network access and Windows system components are still required; this is not an offline Roblox distribution. User preferences, mods and downloads remain under the Windows user profile. Source and license obligations still apply when sharing this modified build.

Build with `tools/Build.ps1 -Publish -NoRestore` using the already restored .NET/Rust toolchain. Preview with `tools/Preview.ps1 -NoRestore`. Build staging and current test evidence reuse `.build`; delivery always defaults to `Release`. `tools/Clean-Generated.ps1` removes redundant generated outputs after verification without touching Release, source or user data. No dependencies were installed for this revision.
Existing account access remains opt-in. The removed RPC/history/cleaner/update surfaces remain retired. New English copy is not fully localized.
