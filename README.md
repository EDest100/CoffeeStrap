# CoffeeStrap

This is my fork of [Froststrap](https://github.com/Froststrap/Froststrap), built on [Fishstrap](https://github.com/fishstrap/fishstrap) and [Bloxstrap](https://github.com/bloxstraplabs/bloxstrap). I wanted more performance and visual tweaks with my own coffee theme, so I made CoffeeStrap! Join the [Discord](https://discord.gg/CZ3P4Rw9D4) for questions or suggestions.

Download the EXE from [Releases](https://github.com/EDest100/CoffeeStrap/releases/latest). **Windows x64 and [.NET 10 x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0/runtime) are required.** The single EXE unpacks its libraries to a local cache; settings and mods stay separate.

I used AI to help build CoffeeStrap and remove features I thought were bloated. The tweaks don't read or edit Roblox's process memory or inject code or shaders. CoffeeStrap isn't affiliated with Roblox.

To build: clone with `--recurse-submodules`, then run `./build/windows/Build.ps1 -Publish` with the .NET 10 SDK, Rust MSVC, Visual Studio C++ tools and PowerShell 7.6+.
